# Futbol Monchon

Proyecto de futbol en Unity.

## Abrir el proyecto

1. Clonar este repositorio con Git.
2. Instalar Unity **2022.3.20f1** desde Unity Hub.
3. En Unity Hub, agregar la carpeta clonada (contiene Assets, Packages y ProjectSettings).
4. Abrir el proyecto y esperar a que Unity importe los assets y restaure los paquetes.
5. Abrir Assets/Football/Scenes/FootballTest.unity.

## Trabajar en equipo

- Versionar Assets (incluidos los archivos .meta), Packages y ProjectSettings.
- No agregar Library, Temp, Logs, obj, Build, Builds ni UserSettings: Unity los regenera.
- Descargar los cambios antes de empezar y crear commits pequenos con mensajes claros.
- Evitar editar la misma escena o prefab al mismo tiempo.
- Los archivos actuales son pequenos y no requieren Git LFS. Si se incorporan binarios grandes, configurar Git LFS antes de agregarlos al primer commit.
